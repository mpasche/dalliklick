# DalliKlick

DalliKlick is a browser based picture guessing game. Choose an image and let other players reveal it gradually.

## Game settings

Choose an image, then define a grid or choose an effect to reveal it. Start or pause automatic reveals, reset the game, or reveal the whole image.

## Offline access

Supported browsers can install DalliKlick as a web app for offline use. Images are not saved in the app.
